関数の応用

Lesson 7Chapter 1
学習の目標

このレッスンでは関数の応用的な知識を学びます。

これまでのレッスンでは、print() や input() など、Pythonが標準で用意している 組み込み関数 や、自作した簡単な関数を使ってきました。

しかし、それだけでは、できることの幅が限られてしまいます。さまざまな課題を解決するために、多くのプログラミング言語では、すでに用意されている関数を必要に応じて読み込み、利用する機能があります。

ここでは「関数の応用」と題し、既存のコードを利用する方法を学びます。

本レッスンの主な内容

  • 既存の関数を利用する
  • モジュールを作成・利用する

本レッスンのゴール

発展的な関数の作り方をいくつか知ること

本レッスンの前提条件

  • Jupyter Notebookを利用する準備ができていること
  • 文字列、数値、セット、辞書、関数の定義などができること
  • オブジェクトが持つメソッドというものの概要を理解していること

Lesson 7Chapter 2
Python標準のモジュールにある関数を利用する

改めておさらいすると、関数には 引数 と 戻り値（返り値） が設定されています。引数は「関数名に続く()で指定するデータ」のことであり、戻り値（返り値）は「関数の処理結果として得られるデータ」を指します。

これまでのレッスンでは、print() のように「複雑な処理を関数名1つ書くだけで実行できるPython標準の関数（組み込み関数）」を利用してきました。しかし、あらゆる処理が組み込み関数として用意されているわけではありません。複雑な処理は自分で作る必要がありますが、その処理を作って1つの自作関数として定義するというのも大変です。

そこで、Pythonにはそのような問題を解決するために「モジュール」という仕組みが用意されています。モジュールには事前に関数が用意されており、それを読み込むことですぐに利用できます。自分で処理を作る必要がないため、利用したい処理が複雑な場合には助かります。

この読み込みの作業を インポート と言い、それによって読み込まれたオブジェクトが モジュール です。

複数のモジュールをひとまとめにしたものを ライブラリ と言います。そのため、以降の内容では、広い意味合いとして「モジュール」ではなく「ライブラリ」という言葉を使っている場合があります。モジュールとライブラリは、ほぼ同じ意味合いで認識いただいてかまいません。

インポートするには、ファイルの先頭に import モジュール名 を記述します。

ここからは、import を使って、いくつかのモジュールを利用してみます。まずは、わかりやすく使えるPython標準のモジュール math を使ってみましょう。

Pythonで標準として用意されている処理のすべてが組み込み関数になっているわけではありません。組み込み関数になっているのは必要最小限なもののみです。組み込み関数以外で必要なものは import で読み込む必要があります。このような仕組みになっているのは、標準で用意されているものすべてを組み込み関数にしてしまうと、プログラムのサイズが非常に大きなものとなってしまうからです。

Lesson 7Chapter 2.1
math（数学関連）

math は数学系の命令がまとまっている、Python標準のモジュールです。math が持つメソッドを関数のように使うことで、さまざまな計算を可能にします。

まずは math を import します。

  • サンプルコード
    • import math
    拡大表示

    importというキーワードに続けて、mathを命令することで、math モジュールを読み込んでいます。

    モジュールに含まれる関数を利用したい場合、リストオブジェクトにおける .count() メソッドなどと似た形で、以下のように記述します。

    モジュール名.関数名()
    拡大表示

    このような記述となるため、厳密には異なりますが「モジュールオブジェクトのメソッドを利用している」という解釈でも問題ありません。

    モジュールオブジェクト math が持っている命令を使ってみましょう。たとえば、mathには、数値の切り上げを行なう ceil() や、数値の切り捨てを行なう floor() があります。 ceil() 関数を実行するなら math.ceil(N) 、同じくfloor() 関数は math.floor(N) と記述して実行します。

  • サンプルコード
    • N = 5.4
print(math.ceil(N))
print(math.floor(N))
    拡大表示
  • 実行結果
    • 6
5

    拡大表示

    Lesson 7Chapter 2.3
    モジュール名や関数名に別名をつける

    用意されているモジュールの名前や関数名がわかりにくい、長いなどある場合、それに変わる別名をつけて実行できます。慣習的に別名をつけて使われるモジュールもあります。別名をつけるには、以下のようにasというキーワードを追加します。

    import モジュール名 as 別名
    拡大表示

    以下に2つ、例を示しました。math モジュールに M という別名を、もう一方では ceil() 関数に tenjo() という別名をつけています。

  • サンプルコード
    • import math as M

M.floor(1.618)
    拡大表示
  • 実行結果
    • 1
  • サンプルコード
    • from math import ceil as tenjo
tenjo(9.11)
    拡大表示
  • 実行結果
    • 10

    以上が、モジュールの集合から任意のモジュールやその関数を取り出し、利用する方法です。math で利用可能な関数の多くは単純な数値演算ですが、他にもより多くの実用的なモジュールがあります。

    以上を基本として、もういくつか見ていきましょう。

    Lesson 7Chapter 2.4
    random（乱数関連）

    randomは、ランダムに数値を取得したり、シーケンスの並びをランダムに変えたりするモジュールの集まり（ライブラリ）です。

    まずはランダムに数値を取得する関数について見てみましょう。

    メソッド名 詳細
    randrange(x) 0 以上 x 未満の整数からランダムな数値を取得する
    randrange(x, y, z) x 以上 y 未満（増分 z）の整数の並びからランダムな数値を取得する。z は省略可能
    randint(x, y) x 以上 y 以下 の整数の並びからランダムな数値を取得する

    試しに使ってみます。結果はランダムですので、実行するたびに変わります。

  • サンプルコード
    • import random

print(random.randrange(11))
print(random.randrange(1, 20, 2))
print(random.randint(1, 10))
    拡大表示
  • 実行結果の一例
    • 0
11
7

    次に、シーケンスに関する random の命令です。

    メソッド名 詳細
    choice(seq) シーケンス seq からランダムに要素を1つ取得する
    choices(seq, k = 1) シーケンス seq から 重複あり でランダムに k 個の要素を取得したリストを返す
    （k はキーワード引数：省略した場合は 1）
    sample(seq, k) シーケンス seq から 重複なし でランダムに k 個の要素を取得したリストを返す
    （k は位置引数で指定必須）
    shuffle(seq) シーケンス seq をランダムに並べ替える

    これらのメソッドを使ってみます。実行結果はランダムなため、毎回変わります。

  • サンプルコード
    • import random

nums = list(range(5))

print(random.choice(nums))
print(random.choices(nums, k = 3))
print(random.sample(nums, 3))

print(nums)
random.shuffle(nums)
print(nums)
    拡大表示
  • 実行結果の一例
    • 2
[1, 1, 3]
[2, 0, 3]
[0, 1, 2, 3, 4]
[4, 1, 0, 2, 3]

    Lesson 7Chapter 2.5
    datetime（日時関連）

    Pythonで日付や時刻を扱う場合は "2018-06-01", "14:39:27" のように文字列として扱うより「日付オブジェクト」「時刻オブジェクト」として扱うと便利です。「3日後」のような日時計算が非常に楽になるからです。

    日時をオブジェクトとして扱うために datetime を使います。datetime 自体は複数の種類（データ型）が扱えるようになっています。

    種類（データ型） 概要
    date 日付情報のみを管理するデータ型
    time 時刻情報のみを管理するデータ型
    datetime 日時の両方の情報を管理するデータ型
    timedelta 時差の情報を管理するデータ型
    timezone タイムゾーンの情報を管理するデータ型

    それでは、datetime を使ってみましょう。まずは現在時刻のオブジェクトを取得してみます。実行する日時によって出力結果は変わります。

  • サンプルコード
    • from datetime import datetime, timedelta, timezone

jst = timezone(timedelta(hours=+9), 'JST')

now_dtm = datetime.now(jst)

print(now_dtm)
    拡大表示
  • 実行結果の一例
    • 2023-08-23 14:33:24.643611+09:00

    jst = timezone(timedelta(hours=+9), 'JST') を分解します。

    timedelta(hours=+9) は「標準時からの時差が +9時間」という情報を保持するオブジェクトが返ります。その時差情報と、日本時間である「"JST"」というタイムゾーンの名前を timezone() の引数として指定し、日本時間のタイムゾーンの情報（オブジェクト）を取得します。

    そのタイムゾーンのオブジェクトを変数 jst に格納しています。

    指定の日時から日時オブジェクトを作りたいときは、指定の日時を文字列で記述したあと、以下のような処理を実行します。

  • サンプルコード
    • dtm_str = "2019-05-25 09:41:36 +0900"
dtm = datetime.strptime(dtm_str, "%Y-%m-%d %H:%M:%S %z")

print(dtm)
    拡大表示
  • 実行結果の一例
    • 2019-05-25 09:41:36+09:00

    strptime() メソッドの最初の引数は文字列になっている日時データ、2つ目は日付データの書式です。1つ目に指定した文字列が、日付のデータとしてどのように指定されているかを2つ目の引数で記述しています。"%Y-%m-%d %H:%M:%S %z" は、それぞれ以下の内容を表す書式指定です。

    • %Y：年（西暦4桁）
    • %m：月（2桁固定）
    • %d：日（2桁固定）
    • %H：時（2桁固定）
    • %M：分（2桁固定）
    • %S：秒（2桁固定）
    • %z：タイムゾーン（標準時からの時差）

    詳しくは公式ドキュメントを参照してください。

  • 基本的な日付型および時間型 - Python 3 ドキュメント

    • 補足：日時計算

    先ほどのコードは、日時情報のオブジェクトをそのまま print() で表示させるだけでした。ここでは、日時情報を便利に使える例として、日時計算をしてみます。

  • サンプルコード
    • print(dtm + timedelta(weeks=1))
    拡大表示
  • 実行結果の一例
    • 2019-06-01 09:41:36+09:00

    timedelta(weeks=1)は「時間差が一週間後」という指定です。一週間（7日）後の日付が自動で計算される上、31を超えても「32日」のようにはならず正しく「6月1日」となります。

    timedelta() には他にも seconds や days といったキーワード引数があり、減算もできるので、日付計算が容易になります。

    参考：

  • 基本的な日付型および時間型 - Python 3 ドキュメント

    urllib（URL関連）

    PythonでURLを扱う場合は urllib を使います。とくに、この中にある request を利用することで、指定のURLを開いて、Webページを読み込むことができます。

    以下のサンプルでは、TechAcademyのトップページを開いて、内容を取得しています。

  • サンプルコード
    • from urllib import request

response = request.urlopen('https://techacademy.jp')
print(response.read().decode())
response.close()
    拡大表示
  • 実行結果
    • <!doctype html>
<html data-n-head-ssr lang="ja" data-n-head="%7B%22lang%22:%7B%22ssr%22:%22ja%22%7D%7D">
...（中略）...
</html>

    request.urlopen() で指定のURLを開きます。

    戻り値（指定したURLから取得した情報）のオブジェクトがもつ read() メソッドで、ページのHTML構造を確認できます。ただし、少々読みにくい状態になっているため、さらに decode() を実行してHTMLの整形を行なっています。

    最後に close() でrequestの処理を終了します。openしたものは、きちんとcloseしましょう。

    なお、取得したHTMLデータから必要な情報を抽出（スクレイピング）したい場合は、取得したHTMLデータの文字列内を検索するか、Python標準ではありませんが「beautifulsoup4」などのスクレイピングの処理を簡単に実装できる外部のライブラリを利用する必要があります。

    Lesson 7Chapter 3
    モジュールを作成・利用する

    以下のコードでは、引数に指定した数値を2乗する square() という自作関数を作っています。

  • サンプルコード
    • x = 4
# 組み込み関数`print()`
print(x)

def square(x):
    return x**2

# 自作関数`square()`
x = square(x)
print(x)
    拡大表示
  • 実行結果
    • 4
16

    しかし、この書き方ですと、このコードを書いたノートブック内でしか square() の自作関数は利用できません。他のノートブックでも利用できるようにする（再利用 と言います）には、書き方を変える必要があります。

    Lesson 7Chapter 3.1
    モジュールを作成する

    自作関数を再利用できるようにするには、以下の流れでモジュールの作成と利用を行ないます。

    1. .py ファイルに自作関数を記載する（モジュールの作成）
    2. その .py ファイルをノートブックで読み込む（import の実行）
    3. 読み込んだモジュール内の関数をノートブックで利用する

    ここでは再びBMIの値を計算する関数をモジュールにします。

    health.py というファイルを作成し、内容を以下のとおりに入力してファイルを保存してください。なお、補足として、新たな関数 standard_weight() を追加しました。

  • サンプルコード
    • def bmi(height, weight):
    ret = weight / height ** 2
    return ret

def standard_weight(height):
    ret = 22 * (height ** 2)
    return ret
    拡大表示

    Lesson 7Chapter 3.2
    作成したモジュールを利用する

    import math などと同様に import health と書いて、health.py をインポートします。そうすることで、上記の関数がメソッドとして利用可能になります。コードセル上では黄色い波線（警告）が health の下に表示される場合がありますが、プログラムの動作には問題ありません。

  • サンプルコード
    • import health
    拡大表示
    import モジュール名 の「モジュール名」と、.py ファイルの「ファイル名」は、同一にします。システムとしてのPythonがモジュールを import するとき、.py と名のついたファイルのなかから、指定されたモジュール名と同じ名前の .py ファイルを探して、読み込んでくれます。

    逆に言えば、モジュール名とファイル名が揃っていないと、モジュールとして読み込めません ので、注意してください。

    これだけでhealth.pyに作成した bmi() と standard_weight() を利用できるようになります。この関数を使ってみる前に、インポートした health.py が、ノートブックのなかでどのように存在しているかを、次のコードで確認してみましょう。

  • サンプルコード
    • print(type(health))
print(health)
    拡大表示
  • 実行結果
    • <class 'module'>
<module 'health' from '/content/health.py'>

    import health で読み込まれた health.py は、ノートブックのなかで module というデータ型のオブジェクトとして存在しています。そのオブジェクトの名前は health です。つまり bmi() と standard_weight() は health オブジェクトのメソッドとして使う ことになります。

    では、次のセルで、この2つの関数を利用してみましょう。

  • サンプルコード
    • height = float(input("身長(m)を入力してください："))
weight = float(input("体重(kg)を入力してください："))

my_bmi = health.bmi(height, weight)
my_standard_weight = health.standard_weight(height)

print(f"BMI値：{my_bmi:.1f}")
print(f"標準体重：{my_standard_weight:.1f}kg")
    拡大表示
  • 実行結果
    • 身長(m)を入力してください：1.7
体重(kg)を入力してください：60
BMI値：20.8
標準体重：63.6kg

    課題再帰的な関数を利用してフィボナッチ数列を実装しよう

    以下の流れで、課題に取り組んでください。

    1. prognum.py という名前のファイルを作成し、以下で説明する「フィボナッチ数列を計算する関数」を定義します
    2. 課題9：再帰的な関数でのフィボナッチ数列.ipynb というノートブックを作成します
    3. 以下の仕様を満たすコードを記述・実行します。コードセルを何個使うかは、自由とします
    4. 完成したら、課題を提出します

    概要

    この課題は、関数を使って「フィボナッチ数列」を実装することがテーマです。フィボナッチ数列は、以下のルールで成り立つ数列です。

    • 1番目の数値は1
    • 2番目の数値は1
    • 3番目以降の数値は、直前の2つの数値の和（以下は例：）
      • 3番目： 1 + 1 = 2
      • 4番目： 1 + 2 = 3
      • 5番目： 2 + 3 = 5
      • 6番目： 3 + 5 = 8
      • …（以下略）…

    このフィボナッチ数列を 再帰的 な関数で実装してください。再帰的な関数とは、以下のように、関数のなかでその関数自身を return している関数です。以下は、整数の階乗（1から指定の数までの連続する整数を掛け算したもの）を求める関数です。

    再帰的な関数の例：

    def factorial(n):
    if n < 2:
        return 1
    
    return n * factorial(n - 1)
    拡大表示

    この関数を使って、たとえば factorial(5) を実行すると、最終的に 5 * 4 * 3 * 2 * 1 が計算されて、120 という計算結果を得られます。

    factorial(5)
    拡大表示
    120

    今回の課題は、再帰的な関数が書かれたファイルをモジュールとしてインポートし、利用していただきます。prognum.py ファイルに「フィボナッチ数列を計算する関数」を定義します。

    フィボナッチ数列を計算する関数が定義できたら、その関数を利用するコードを、課題9：再帰的な関数でのフィボナッチ数列.ipynb に記述します。

    仕様

    • prognum.py ファイルに「フィボナッチ数列を計算する関数」を定義します。関数名および引数の名前は自由とします。処理内容は以下のとおりです：
      • 1番目の数値は1
      • 2番目の数値は1
      • 3番目以降の数値は、直前の2つの数値の和（以下は例：）
        • 3番目： 1 + 1 = 2
        • 4番目： 1 + 2 = 3
        • 5番目： 2 + 3 = 5
        • 6番目： 3 + 5 = 8
        • …（以下略）…
      • 3番目以降の数値に関する部分で、その関数自身を指定して return することで、再帰的な関数になります。この関数を再帰的な形にしてください。無限ループに注意しましょう！
    • 課題9：再帰的な関数でのフィボナッチ数列.ipynb で prognum.py をインポートしてください
    • 「何番目の数値を求めたいか」をキーボードから入力できるようにしてください。（数値が入力される前提でかまいませんので、例外処理は不要です）
    • フィボナッチ数列を計算する関数を実行する命令を記述してください。キーボードから入力した数値を引数に指定しましょう
    • 計算結果の数値を画面に出力してください
